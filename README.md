# Climate Change Data Analysis

## Overview
This project analyzes climate change data to understand long-term trends in temperature and weather patterns.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Features
- Data cleaning and preprocessing
- Trend analysis over time
- Data visualization of temperature changes

## What I Learned

- Data visualization techniques
- Identifying patterns and trends in large datasets
